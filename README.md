# Nexus — Espacio Comunitario de Apuntes

¡Bienvenid@ al repositorio oficial de **Nexus**! Una aplicación web interactiva, moderna y visualmente atractiva diseñada para centralizar, organizar y potenciar el intercambio de material de estudio entre estudiantes y profesores de forma dinámica, evitando el caos de los grupos de mensajería tradicionales.

**NOTA IMPORTANTE DE USO: VERSIÓN DEMO / PROTOTIPO VISUAL**  
Este repositorio contiene una **maqueta interactiva (Demo)** diseñada exclusivamente para ejemplificar de forma visual la estructura, el diseño y la experiencia de usuario de la plataforma. La navegación, el chat y el perfil son **simulaciones en tiempo real que no se guardan en una base de datos**. No funciona en su totalidad ni cuenta con un servidor real conectado.

---

## Características Principales

El proyecto replica de forma fiel un flujo integral estructurado en base a necesidades reales del aula:

*   **Glassmorphism Estético:** Interfaz fluida basada en un diseño neumórfico y de vidrio esmerilado con fondos orgánicos animados.
*   **Sección Estudiante:**
    *   Ingreso instantáneo mediante códigos de clase.
    *   Buscador interactivo de materias con filtros selectivos (Ver todo el contenido vs. Ver solo mi grupo).
    *   Módulo para plantear dudas que serán respondidas únicamente por docentes para mitigar la desinformación.
*   **Chat del Grupo en Tiempo Real:** Espacio de mensajería interactivo para debatir tareas y coordinar entregas con el resto de la clase. 
*   **Gamificación (Economía Virtual):** Perfil de usuario integrado con un sistema de **Moneditas Virtuales** y medallas de logros (*Colaborador, Buen Compañero, Constante*) que recompensan la interacción.
*   **Sección Profesores:** Panel de respuestas a dudas y biblioteca colaborativa multimedia para compartir nuevas dinámicas y formas de enseñar.
*   **Modo Invitado:** Acceso de libre lectura para explorar recursos públicos sin necesidad de un grupo asignado.

---

## Tecnologías Utilizadas

Este proyecto fue construido desde cero de forma modularizada utilizando estándares modernos de desarrollo frontend:

*   **HTML5:** Estructura semántica de las pantallas y componentes de navegación.
*   **CSS3 moderno:** Diseño responsive, paleta cromática vibrante con variables (`:root`), efectos de desenfoque (`backdrop-filter`) y animaciones orgánicas de fondo.
*   **JavaScript (ES6):** Manejo dinámico del DOM para la navegación instantánea entre pantallas sin recargar la página y motor del chat interactivo.
